# 戒网瘾学校兔子洞 · THE CAMP ICEBERG

一个本地静态网站：8 个层级、120 个词条、48 条证据链接，按“越深越冷门、越接近规则本身”的顺序排列。

线上地址：**https://scp55154-pixel.github.io/wangjie-iceberg/**

![首页预览](preview-hero.png)

## 运行

需要 Node.js（本机已安装 v24）。在本目录打开终端：

```powershell
node server.js
```

然后访问 <http://127.0.0.1:8790/>。也可以双击 `启动网站.cmd`，它会启动服务器并打开浏览器。

网站没有外部依赖、没有构建步骤、没有分析脚本。所有数据都在 `data/` 目录，直接改 JSON 风格的 JS 文件即可增删词条。

### 可以直接分享的 URL

- `?q=13号室` — 预填搜索
- `?cat=未证实` — 预选分类
- `#entry=rule-86` — 直接打开某个词条
- `?q=杨永信`、`?cat=案件` 也可以组合使用

## 结构

- `index.html` — 页面骨架与文案
- `styles.css` — 深色冰山视觉系统
- `app.js` — 渲染、搜索、分类筛选、弹窗、深度滚动、localStorage 已读状态
- `data/core.js` — 数据注册器
- `data/sources.js` — 48 条来源，格式为 `[标题, 发布者, 年份, 类型, URL, 备注]`
- `data/tiers-1.js` — 第 1–2 层（30 条）
- `data/tiers-2.js` — 第 3–4 层（30 条）
- `data/tiers-3.js` — 第 5–6 层（30 条）
- `data/tiers-4.js` — 第 7–8 层（30 条）

词条字段：`id`, `title`, `en`, `teaser`, `depth`, `category`, `tags`, `body`, `why`, `sources`, `status`, `evidenceNote`。

## 证据标注

每条词条都有 `status`，在卡片与弹窗中显示：

- `已证实` — 有当时的影像、官方文件或多个独立报道相互印证
- `已判决` — 有法院判决/刑期
- `媒体调查` — 依赖记者核查与受访者叙述
- `当事人陈述` — 幸存者、家属或前员工的回忆
- `官方回应` — 被举报方/监管部门的说法
- `争议` — 双方各执一词，图中并列呈现
- `未证实` — 目前只有传闻或无法独立确认的视频

`evidenceNote` 说明该条证据能证明到什么程度、哪里存在冲突。来源不等于结论；“有链接”不等于“已定罪”。

## 重要说明

这不是一份完整的调查报告，而是一张索引。涉及未判决案件时，文中使用“举报/指控/受审/被指”等表述，不预判结果；涉及个人时，请以法院最终裁判为准。不要联系、骚扰、攻击任何被提及的个人或组织，也不要去找当事人。
